提案 1 / 3

AI BI：企業內部的 AI 加速器

讓同仁用「問的」、用「說的」，就能查資料、看報表。

😣 痛點

  • 要一個數字，得排隊等 BI／資料團隊
  • 文件與指標定義散落各處，找半天
  • 把公司資料貼到公開 AI，有外洩風險

💡 解法（MVP）

  • Ask Me Anything Bot：用 RAG 回答內部文件與指標定義
  • Speech to BI：語音／自然語言 → SQL → 圖表
  • 以範例資料庫（模擬企業資料）展示

🎯 成果展示

  • Demo：問「上個月各品類營收？」→ 自動出圖
  • 驗收：回答正確率、回應時間
  • 權限測試：不同角色只看得到該看的資料

🛠 主要工作

RAGMCP範例資料庫權限管理效能資安
提案 2 / 3

可商業化的雲端服務

鎖定一個產業的真實痛點，做出客戶願意付費的 SaaS。

😣 痛點

  • 許多中小型店家、事務所仍靠 LINE、紙本、Excel 處理預約與客服
  • 人力有限，重複性工作佔掉大量時間

💡 做法

  • 訪談 5–10 位目標客戶，挑出最痛的一件事
  • 做出 MVP（例如 LINE 預約＋AI 客服）
  • 找試用客戶，依回饋迭代

📌 參考案例 （市面產品，非本人作品）

診所小幫手：治療所的預約、個案紀錄、營運報表、AI 客服

CaseLight：律師事務所的 AI 受案，自動整理案情摘要

🛠 主要工作

需求訪談開發市場導入

驗證指標：訪談數、試用客戶數、付費意願

提案 3 / 3

台股交易：撈錢？賠錢？

用資料驗證交易想法：先回測、再模擬，最後才小額實單。

😣 問題

  • 憑感覺交易，很難知道策略到底有沒有用
  • 沒算手續費、稅與滑價，回測容易過度樂觀

💡 流程

  • 券商 API 取得行情與歷史資料
  • 研究策略 → 回測（含交易成本）
  • 模擬交易 → 小額實單

🎯 成果展示

  • 回測報告：報酬率、最大回撤、勝率
  • 自動交易系統 Demo
  • 風控：停損、部位上限、交易紀錄

🛠 主要工作

券商 API研究策略回測設計交易系統
